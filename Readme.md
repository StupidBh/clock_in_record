# AttendanceApp

AttendanceApp 是一个基于 Qt 6 的 Windows 桌面考勤记录工具。应用以月历为主要入口，按日期保存到达和离开时间，计算实际工时、迟到、早退、加班和缺少的标准工时，并汇总月度统计。数据使用本机 `QSettings` 保存，不需要数据库或外部网络服务。

## 功能

- 在月历中点击日期，编辑到达时间、离开时间以及是否计入加班目标统计；已保存的时间会显示在日期格中，并明确标记不计入目标的记录。
- 使用主界面的“今天”按钮可以从其他月份快速返回并选中当天。
- 新建当天记录时，如果当前时间早于默认离开时间，到达时间会自动填充为当前分钟；其他新记录使用默认到达时间。
- 计算实际工时、标准工时、休息时间、迟到、早退、标准工时缺口和标准时段外的加班。午餐、晚餐休息会从对应时间范围中扣除。
- 在右侧“全局工作时间设置”中配置标准上下班时间、午餐和晚餐休息、餐补规则、日均加班目标，以及是否使用加班抵扣缺少标准工时；设置入口收起时固定在统计区下方，展开后原位显示并独立滚动，窗口高度不足时右栏整体滚动。
- 月度统计显示工作天数、日均加班、相对目标的差额、工时缺口和餐补次数。取消某日的“计入加班目标统计”后，该日不计入工作天数，但其有效加班仍计入总加班时长，因此日均加班和相对目标的差额都会随工作天数变化。
- 加班抵扣开启时，日详情按当天抵扣，月度统计按整月加班和缺口汇总后抵扣；默认关闭。
- 右键点击有记录的日期可以删除记录，也可以在日期编辑对话框中删除。
- 应用使用本地单实例通道启动；再次运行时会激活已打开的窗口。界面会跟随系统的浅色/深色配色方案。

## 默认设置

| 设置 | 默认值 |
| --- | --- |
| 标准上班时间 | `09:00` |
| 标准下班时间 | `18:00` |
| 午休 | `12:30`–`13:30` |
| 晚餐休息 | `18:00`–`18:30` |
| 餐补统计 | 开启 |
| 餐补起算时间 | `21:00` |
| 日均加班目标 | `2.5` 小时（150 分钟） |
| 加班抵扣缺少标准工时 | 关闭 |

全局设置会自动保存。标准上下班时间、午餐和晚餐休息以及餐补起算时间作为新建记录的默认作息，并随每条记录保存快照；之后修改这些作息字段不会改变历史记录的基础工时计算。餐补统计开关、日均加班目标和加班抵扣是当前全局统计规则，修改后会重新影响历史月份的统计结果，其中加班抵扣也会影响历史记录的日详情。周六和周日的新记录默认不计入加班目标统计。

## 环境要求

- Windows x64
- CMake 4.3 或更高版本
- Visual Studio 2026（生成器版本 18，MSVC 19.50）或更新版本
- Qt 6.11.1，必须包含 `Core`、`Widgets` 和 `Network` 模块，并使用与 MSVC 兼容的构建

项目要求通过 `Qt6_DIR` 指定 Qt 的 CMake 配置目录。不要把本机 Qt 路径提交到仓库。例如：

```powershell
-DQt6_DIR=D:/path/to/Qt/6.11.1/msvc2022_64/lib/cmake/Qt6
```

所有 C++ 目标使用 C++23，并关闭编译器扩展。生成的文件位于 `build/` 和 `bin/<Debug|Release>/`，这些目录不应提交。

## 构建、运行与测试

在 PowerShell 中配置 Visual Studio 多配置构建目录：

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64 `
  -DQt6_DIR=D:/path/to/Qt/6.11.1/msvc2022_64/lib/cmake/Qt6
cmake --build build --config Debug
.\bin\Debug\AttendanceApp.exe
ctest --test-dir build -C Debug --output-on-failure
cmake --build build --config Release
```

配置阶段默认启用 CTest。当前回归目标包括：

- `ApplicationUiTests`：主窗口结构、日期记录保存和删除
- `ApplicationThemeTests`：浅色/深色主题及控件对比度
- `AttendanceSettingsTests`：全局设置、记录持久化、旧格式迁移和月度抵扣
- `AttendanceSummaryTests`：月度汇总和文本格式化
- `WorkTimeCalculatorTests`：工时、迟到、早退、休息、无效范围和加班计算

Windows 构建在 Qt 包提供 `windeployqt` 时，会在构建后自动把运行所需的 Qt DLL 和插件部署到可执行文件目录。项目没有 CMake install 步骤。

## 项目结构

```text
Core/
├─ Application/   # 程序入口、主窗口和主题
├─ Attendance/    # 考勤数据结构、工时计算和格式化
├─ Calendar/      # 月历控件及日期操作
├─ Settings/      # 全局设置和日期记录对话框
└─ Widgets/       # 通用界面组件
tests/             # CTest 回归测试
resources/         # 应用图标和 Qt 资源清单
```

各功能目录在顶层放置公共 `*.h`，实现文件放在对应的 `src/` 子目录。贡献代码前请阅读 [AGENTS.md](AGENTS.md)。

## 数据存储与重置

正式应用通过 `QSettings` 使用当前 Windows 用户的注册表保存设置和考勤记录：

```text
HKEY_CURRENT_USER\Software\MyCompany\AttendanceApp
```

记录按 `yyyy-MM-dd` 分组保存，并包含到达/离开时间、加班目标统计标记和作息快照。应用启动时会为旧记录补齐缺失的作息字段。数据不会随构建目录删除；如需完全重置，请退出应用后先备份，再使用注册表编辑器删除上述 `AttendanceApp` 项。
